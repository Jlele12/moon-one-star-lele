One star, the Moon: shows up every night without being asked, full or broken, and still gets blamed for werewolves. Consistency deserves better.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

The line is written to `/output/entry.txt` on every run, byte for byte the same.
